# Kafaa Premium — الموقع الرسمي لخدمة كفاءة بريميوم

الموقع الرسمي التعريفي لخدمة **Kafaa Premium** الخاصة بتطبيق **كفاءة** للتحضير لاختبار الكفاءة الوطني العراقي.

## المزايا والخصائص
- ⚡ **خفيف وسريع**: مبني باستخدام React + TypeScript + Vite + Tailwind CSS.
- 📱 **Mobile First**: تجربة استخدام متجاوبة ومثالية لجميع أحجام الشاشات.
- 🌐 **RTL كامل**: مصمم باللغة العربية مع خط Cairo الأكاديمي الواضح.
- 💰 **باقات وأسعار موحدة**: مصدر بيانات مركزي في `src/data/plans.ts`.
- 💬 **تواصل مباشر**: روابط محادثة جاهزة عبر WhatsApp وTelegram بدون وسطاء أو بوابات دفع داخلية.

## تشغيل المشروع محلياً

```bash
# تثبيت الحزم
npm install

# تشغيل بيئة التطوير
npm run dev

# تشغيل الاختبارات
npm test

# فحص الكود
npm run lint

# بناء نسخة الإنتاج
npm run build
```
